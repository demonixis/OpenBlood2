# M0 — New Project Foundation

**Completed on Linux/Wayland/Vulkan, 15 October 2026.** The independent project is [Blood2](../../../README.md). Its Git repository has been initialized; sources are saved in its working tree without a commit or remote. The six earlier repositories and original game installation remain unchanged.

M0 implements a new CMake/C++20 application with SDL `main`, SDL_GPU, spdlog and an optional Dear ImGui in-game inspector. It does not implement original-game objects, level loading or archive readers. M1 is the next milestone.

## Delivered Behavior

- A real GPU window with frame presentation, resizing and orderly shutdown, without a headset.
- An inspector showing backend/device, library revisions, frame state and external archive metadata; F1/close-button visibility control; empty Objects and Resources tabs.
- Configurable content location through a local file, environment variable or command line. Missing/invalid inputs fail clearly before video initialization.
- A headless `--check-data` mode and bounded `--gpu-smoke` run. Optional PNG readback enables visual verification of actual GPU output.
- Separate Debug/inspector and Release/no-inspector presets, tests and documented Windows/macOS build procedures.

Only `engine` and `blood2_app` are created now. The planned `blood2_game` target is deferred to M1 rather than added as an empty placeholder. There is no ECS/EnTT, inherited renderer, generic editor framework or dependency on a prototype checkout. [Provenance and dependency manifest](../provenance.md).

## Reproduction

From `Blood2/`, the ignored local presets/configuration are already populated:

```sh
cmake --preset local-debug
cmake --build --preset debug -j 8
ctest --preset debug
cmake --preset local-release
cmake --build --preset release -j 8
ctest --preset release
./build/debug/blood2 --check-data
./build/debug/blood2 --frames 3 --capture .cache/local-inspector.png
```

For other machines, use the public presets and explicitly set `BLOOD2_TEST_DATA_DIR`/`BLOOD2_GPU_TESTS` as described in [the project README](../../../README.md). The default portable suite contains 11 tests. Full compiler commands and resolved dependency hashes are in [the evidence manifest](evidence/m0.json). Project code and configuration hashes identify this uncommitted implementation snapshot.
